# 本番素材仕様 / Asset spec

役割分担: **Remotionで描画** = 照明・光・影・粒子・幕の動き・テロップ・全アニメーション。**画像生成で用意** = 質感のある静止素材（下表）。素材差し替え後もアニメーションは作り直し不要（リグ／タイムライン／座標は設定側）。

| 素材 | 形式 / 推奨サイズ | 備考 | 現状 |
|---|---|---|---|
| 劇場背景（壁・床・通路） | PNG/JPG 3840×2160, 照明なしの暗めプレート | `TheaterBackground` と差替 | SVG仮 |

## 画像素材の不足箇所（ChatGPT等で次に生成）
1. 高級劇場の壁・床プレート（照明なし）
2. ボルドー幕+バランスの前景PNG（透過）
3. ゲスト（まず1人）：セミリアル、正面、タキシード。パーツ分割（頭・胴・腕・脚・靴）+ 表情3種
4. 立体感のあるワイングラス（透過）
5. 客席シルエット、真鍮スクリーン枠

## 音声の状態
全て **仮音源**。BGM/環境音/SFXは `scripts/gen_audio.py` による自作合成（権利問題なし）。ナレーションは macOS `say`（Reed）の仮声で、高級な上映前アナウンス品質ではない。本番は Canva / ElevenLabs で生成した男性の落ち着いた声に差替え。

## 更新: 本番素材の差し替え済み（背景・人物リグ）
- 背景: `public/bg/theater.png`（1672×941 → 1920×1080に拡大）。スクリーン枠・幕・客席縁・スポットライトは画像側。テロップ領域=左（`config/theme.ts` の `SCREEN`）、人物=右。
- 人物: `public/tuxedo/assets/*.png` + `src/config/tuxedoRig.json`（配置/ピボット）。`src/config/rigs.ts` に登録、`guests.ts` の `rig` で参照。
- 影: 同じリグを黒シルエット化（独立ポーズ）。`guests.ts` の `shadow` で位置・大きさ・傾き・ぼけを調整。
- 別ゲストのリグ追加: assets をコピー → `rigs.ts` に登録 → `guests.ts` の `rig` を変更。

### 素材の不足・制約（リグ側）
- 乾杯の腕は `arm_right` の回転のみ（±数度想定のため、大きな角度は不自然）。肘の曲げ差分なし。
- 影の「高く掲げる」ポーズは腕回転 −118° の流用。専用の「腕を上げた」パーツがあれば自然さが上がる。
- 靴と脚の接続が不自然（靴を上へ32px補正、足元に隙間感が残る）。足首〜靴が一体のパーツが望ましい。
- 胴体の肩が筋肉質に膨らみ、腕も太い（元画像と体格が異なる）。
- 蝶ネクタイ直し: 腕差分は1種。手とネクタイの重なりは簡易（グラスは常に最前面）。
- 表情: 通常/横目/会釈の3頭のみ。まばたき・口の差分なし（頭の切替はクロスフェード）。
- 首と頭の接続に継ぎ目が見える場面あり（頭差分ごとに首形状が異なる）。
