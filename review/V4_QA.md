# V4 品質評価 (out/drink-warning-v4.mp4)

## 方向転換の要点
V3（暗く重い、影が不気味）→ V4「高級映画館 × コミカルな上映前マナーCM」。明るく暖色で、影は幽霊ではなく“ほろ酔いの愉快なシルエット”。V1〜V3 のMP4は未変更（V2/V3 は md5 一致を確認）。V3 のソース/音声は `archive/v3-src/`, `archive/v3-audio/`。

> 依頼文の効果音の項目が途中で途切れていた（「影がふらつくときの軽…」まで）。そこは「軽快でコミカルな音」と解釈して実装した。他に見落とした指定があれば反映が必要。

## 変更点
**照明・色**
- 背景画像を明るく持ち上げ（明度×1.55、彩度＋、暖色化）。暗幕の減衰（bgDim）と周辺減光を大幅に弱め、全体の平均輝度を V3 の約 36 → V4 の約 69 に（約1.9倍）。
- スポットは柔らかく、シャンパンゴールドの光だまり＋左上からのブルーム。ボルドーの幕・金枠・アイボリーの文字を活用。
- スクリーン: 黒い空洞をやめ、ボルドーのタイトルカードに。人物は少し明るく暖色に。
- 影: 黒の不気味なシルエットから、壁に溶ける柔らかい茶色寄りの半透明（乗算・不透明度 0.62）に。
**影の演出（コミカル）**
- ほぼ静止の本人 → 影だけが勝手に動く、という構造を維持。
- 影がグラスを高く掲げて「チン！」（星のきらめき＋文字）、ぴょんと小さく跳ねる → ふらふら（左右にスウェイ、ぐるぐる星） → 気づかれて慌てて直立（「！」＋汗のしずく＋跳ね＋びっくり線）。すべて影のリグの姿勢に追従して配置。
- 画面の「ほろ酔いメーター」: 本人 0% のまま、影が 38%→93% と上がり、直立で 0% に戻る。初見でも「影だけ酔っている」と分かる。
**音**
- BGM: 暗い重低音を廃止。軽快なスウィングジャズ（120 BPM、ウォーキングのピチカート・ベース、ブラシ、ピチカートのメロディ）を合成。テンポは解析で 120.0 BPM を確認。
- SFX: 明るい「チン！」、点灯のハープ風グリッサンド、影の持ち上げのスウィッシュ、ふらふらのスライドホイッスル、慌てて直立の「ポン！」、締めの明るいチャイム。
- 笑いの静寂: 5.4〜6.45秒はBGMを消し、その中で「ポン！」だけが鳴る（鳴るタイミングは影の直立に同期）。6.5秒でちょうど拍の頭から音楽が戻る。
- ナレーション中のBGMは約半分に（音声の聞き取り優先）。

## 未解決の問題
1. BGMは自作の合成音で、生演奏のスウィングの質感には届かない可能性が高い。→ 同テンポ（110〜125BPM）のライセンス済みの曲に差し替えるのが望ましい。差し替え時は `config/audio.ts` の `bgm` を変更し、`MIX.gap`（5.4〜6.45秒で消音）と拍の位置（6.5秒＝拍頭）を合わせる。
2. ナレーションは macOS の合成声（仮）。コミカルで上品な男性ナレーションの本番音源が必要。
3. 影は分割リグ由来で、本人（全身PNG）より肩が太い。腕の付け替え（グラスが反対の手に移る）は仕様上の演出。
4. 人物は静止に近い（表情・視線の変化なし）。全身PNGの制約。
5. 床の反射・接地影はプログラム描画で、背景の床質感とは完全には一致しない。
6. 日本語フォントは macOS 標準の明朝/ゴシック依存。
7. 影の代替案（オリジナルのイラストキャラクター版）は未実施。現行の影＋メーター＋マークで「不気味さ」は解消したと判断したが、通し再生で不気味さが残る場合の保険案。
