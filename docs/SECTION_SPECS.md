# 全9セクション実装仕様（90秒 / 1920×1080 / 30fps）

尺と開始位置の唯一の定義: `src/movie/timeline.ts`。各セクションの要点: `src/movie/sectionSpecs.ts`。

| No | 区間 | 内容 | 状態 |
|---|---|---|---|
| 01 | 00–08s | 映画館オープニング | 仮表示 |
| 02 | 08–15s | 上映前のご案内 | 仮表示 |
| 03 | 15–38s | 飲み過ぎ注意（先頭10秒はサンプル2人が交代出演、残りはゲスト10人を後から登録） | 一部実装 |
| 04 | 38–50s | 写真・動画撮影OK | 仮表示 |
| 05 | 50–61s | 拍手・歓声大歓迎 | 仮表示 |
| 06 | 61–68s | まもなく本編スタート | 仮表示 |
| 07 | 68–82s | 新郎新婦の映画予告編 | 仮表示 |
| 08 | 82–87s | TATSUYA & NAMI | 仮表示 |
| 09 | 87–90s | 入場への接続 | 仮表示 |

各セクションの文言・映像・音は `src/movie/sectionSpecs.ts` を参照。

## 共通ルール
- 明るく、おしゃれで、少しシュール。ホラー・無表情の不気味さ・重低音は禁止。
- キャラクターは SVG（`src/character/`）。ゲストは**1人ずつ交代**で出演し、同時には出さない。
- 色・フォント・モーション・音量は `src/movie/design.ts` から使う。
- 音楽・ナレーション・写真は差し替え前提。`src/config/audio*.ts` の `placeholder: true` を目印にする。

## ゲスト10人
`src/guests/guests.ts` に10スロット。スタイルは `src/character/styles.ts` に追加し、`characterId` を指定する。
