# V3 品質評価 (out/drink-warning-v3.mp4)

## 方針
人物 = 最初の全身PNG（`public/tuxedo/guest01_full.png`）をそのまま使用。関節アニメーションなし。影だけ分割リグの黒シルエットで独立して動かす（継ぎ目が出ない）。V2（`out/drink-warning-v2.mp4`）とV1（`out/drink-warning-sample.mp4`）は未変更（V2 は md5 一致を確認、旧ソースは `archive/v2-src/`）。

## V2からの変更
- 影のグラス: ぼけたPNGをやめ、コード描画の鮮明なワイングラスのシルエットに（`PuppetRig.tsx`）。影はぼかしも弱めた（足元1.2px / 頭2.4px）。
- 影の乾杯: 本人が静止した後、約3.3秒で反対側の手にグラスが移り、頭と重ならない右上へ掲げて**約0.7秒静止**（読ませる間）→ふらつき→気づかれて直立。
- 位置: 影の位置と大きさを調整し、グラスが右カーテンで見切れないように。
- 人物の馴染み: 暖色グレーディング、左上スポットに揃えた縁の光、床への薄い反射（鏡像）、二重の接地影、微かな体重移動の揺れ。
- 光源: スポットを左上に統一（`SPOT`）。影は右に落ちる。床の光だまりを足元に合わせた。
- カメラ: 微小な手ぶれ風ドリフト（±3px）＋最大3%の押し込み。
- テロップ: 約0.2秒早く表示（6.4秒）。「飲み過ぎ注意」「祝杯は、エンドロールまで美しく。」「WEDDING CINEMA」が**完全表示される時間 約2.1秒（7.55〜9.65秒）**。
- 点灯: より緩やかに（0.27〜1.7秒）。終端は完全な黒まで暗転。
- 音: BGM（重低音のパルスと終盤の微かな煌めきを足した）、リバーブ付きのグラス音、影のグラスが離れる「スウィッシュ」、ふらつき音、締めの低音を再生成（`scripts/gen_audio_v3.py`）。ナレーションの実測音声長（①約2.2秒 ②約2.75秒）に合わせて配置、効果音と重ならないよう調整。

## 未解決の問題
1. ナレーションは macOS の合成声（仮）。上映前アナウンスらしい男性の落ち着いた声には達していない。→ 本番音源への差し替えが必要。
2. BGM・効果音・環境音は自作の合成音（権利問題なし）だが簡素。→ 作曲/収録済みの素材が望ましい。
3. 影は分割リグ由来のため、本人（全身PNG）と体格・肩幅が少し違う（肩が太い）。黒いシルエットなので目立たないが、完全一致ではない。→ 全身PNGから腕を分離した画像（腕を下げた状態/グラスを持つ腕）があれば一致する。
4. 影の腕の付け替え（グラスが反対の手に移る）は、近距離で見るとやや唐突に見える可能性。コミカルな演出として意図。腕を上げた専用パーツがあれば自然さが上がる。
5. 床の反射・接地影は控えめなプログラム描画で、背景画像の床の質感と完全には一致しない。→ 足元の接地を含めた合成済みの人物画像があれば改善。
6. 人物の動き（息づかい、会釈、振り向き）は全身PNGの小変形のみ。表情の変化や視線の移動はない（素材の制約）。

## 本番利用の判断
上映プレビューとしては使える水準だが、**本番上映には、ナレーションと音響素材の差し替え、通し再生と聴取の確認が必要。**
